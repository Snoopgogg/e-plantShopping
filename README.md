# Paradise Nursery

A simple React shopping-cart application for an online plant nursery.

## Features
- Landing page with company name and Get Started button
- About Us page/section
- Product catalogue with six houseplants grouped by category
- Add-to-cart buttons that disable after an item is added
- Cart count in the navigation bar
- Cart page with quantity controls, item removal, subtotal, and a Checkout Coming Soon message
- Responsive styling

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL shown in your terminal.
