# e-plantShopping

Paradise Nursery Shopping Application - A React-based e-commerce platform for browsing and purchasing plants online.

## Features
- Landing page with company name and Get Started button
- About Us section with company details
- Product listing page with multiple plant categories
- Shopping cart with add, remove, and quantity management
- Responsive design with Bootstrap styling

## Technologies Used
- React
- Redux Toolkit
- Vite
- CSS

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
